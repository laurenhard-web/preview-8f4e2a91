# Full-Stack Database, File/Image Storage & PDF Catalog Architect

## Назначение
Запрещает сдавать бизнес-приложения в виде «одного JS-массива без базы данных и файлов». Для каждого проекта в обязательном порядке создаются:

1. **Реляционная база данных (`storage/db/*.sqlite3`)** в режиме WAL с полнотекстовым индексом `FTS5`:
   - Таблицы `vehicles`, `catalog_groups`, `scheme_callouts`, `oem_parts`, `cross_references`, `media_assets`, `pdf_catalogs`, `work_orders`.
   - Экспорт SQL-дампа (`schema_and_seed.sql`) и JSON-индекса для работы как через серверный API, так и на статическом хостинге (GitHub Pages).
2. **Файловое хранилище и Хранилище Изображений (`storage/images/`, `storage/schematics/`)**:
   - Реальные скачанные фото запчастей и детализированные инженерные SVG-схемы узлов с интерактивным зумом/панорамированием и кликабельными хотспотами.
3. **Генератор настоящих PDF-каталогов (`storage/pdf_catalogs/*.pdf`)**:
   - Формирование валидных многостраничных PDF-документов с заводскими ведомостями артикулов, PR-кодами, кросс-аналогами и печатными Заказ-Нарядами СТО.
